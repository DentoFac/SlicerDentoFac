# Contributing to DentoFac

Contributions that improve a unified, reliable dental workflow in 3D Slicer are
welcome. Please open an issue for substantial proposals, then submit focused
pull requests with the relevant tests and documentation.

## Contribution expectations

- Keep DentoFac-owned code and documentation compatible with Apache License 2.0.
- For an incorporated extension, model, or dependency, provide its upstream
  source, revision, license, notices, citation requirements, and a summary of
  DentoFac-specific changes for `THIRD_PARTY_NOTICES.md`.
- Do not remove or alter third-party copyright notices, licenses, or required
  attributions.
- Keep workflow-specific behavior inside its module and shared behavior in
  DentoFacLib only when it is broadly reusable.
- Add or update tests appropriate to the change, and describe the validation
  performed in the pull request.

We aim to contribute generally useful fixes upstream where practical and to
work respectfully with the maintainers whose work DentoFac builds upon.
